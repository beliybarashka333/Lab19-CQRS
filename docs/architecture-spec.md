# Краткое описание архитектуры

Лабораторная работа построена на паттерне **CQRS** (Command Query Responsibility Segregation).

Система разделена на две независимые стороны:

1. **Command side (запись)** — команды, обработчики команд, доменная модель `Order`, репозиторий записи `IOrderWriteRepository`.
2. **Query side (чтение)** — запросы, обработчики запросов, DTO чтения, репозиторий чтения `IOrderReadRepository`.

Связь между сторонами — только через доменные события (`OrderCreatedEvent`, `ProductAddedEvent` и др.), по которым `OrderProjection` обновляет хранилище чтения.

Правила:
* Команда ничего не возвращает и не используется для чтения данных.
* Запрос не изменяет состояние системы.
* Обработчики записи не используют модели чтения, обработчики чтения не используют доменную модель `Order`.
